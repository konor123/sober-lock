# 맑은잠금 (sober-lock)

술이나 졸림에 취해(깨어 있지만 판단이 흐려진 상태) 실수하지 않도록 선택한 앱을 잠그는 안드로이드 앱.

잠꼬대나 몽유증세와는 무관하며, 자는 동안의 무의식 행동을 대상으로 하지 않는다.

## 해제 방법

시간 잠금, 지적 문제(수학 등), 손떨림 테스트는 사용하지 않는다 (사용자 지시).

### 1순위: 랩/발음 테스트

매번 랜덤으로 잰말/랩 한 줄을 보여주고, 한국어 음성인식(SpeechRecognizer)으로 판정한다.

- 통과 기준: 단어·문자 일치도 70% 이상, 15초 이내 완료
- 매번 문장이 바뀌므로 미리 녹음한 목소리로는 풀 수 없다
- 이어폰 마이크가 연결돼 있으면 랩 인식에 사용한다

### 폴백(시끄러운 환경용): 점 따라가기 + 반응속도 테스트 (10초 고정)

시작 전 1초간 주변 소음을 측정해 시끄러우면 랩을 강요하지 않고 점 테스트로 자동 전환을 제안한다. 사용자가 수동으로 선택할 수도 있다.

- 10초간 랜덤 위치에 점 5-6개, 뜨자마자 터치
- 반응시간 + 정확도 측정
- 통과 기준: 평균 반응 700ms 이하·적중률 70% 이상, 또는 기준 측정값이 있으면 기준 +40% 여유

## 실패·긴급

- 실패 시 5분 쿨다운 (카운트다운 표시, 그 전 재도전 불가)
- 긴급 해제 버튼: 5초 꾹 누르기 + 확인 대화상자("정말 긴급한가요? 해제 기록이 남습니다") 후 10분간 전체 해제, 로그 기록
- 전화/다이얼러/119는 잠금 대상에서 제외 (기본 제외, 잠글 수 없음)

## 설정 (앱 내 옵션에서 사용자가 직접 정함)

- 잠글 앱: 설치된 실행 가능 앱 목록에서 다중선택 (자기 자신, 전화, 설정은 제외/경고)
- 해제 유지 시간: 5분 / 10분 / 30분 / 화면 끌 때까지 (기본 5분)
- 점 테스트 기준 측정 버튼: 멀쩡할 때 3회 측정해 평균 반응시간 저장
- 로그 뷰: 최근 200줄
- 접근성 활성화 버튼, 배터리 최적화 제외 버튼
- 다크모드: 시스템 따름

## 잠금 방식

AccessibilityService TYPE_WINDOW_STATE_CHANGED로 전경 패키지를 감지하고, 잠긴 앱이면 LockActivity를 띄워 차단한다. 해제 성공 시 해제 유지 시간만큼 풀어준다. 화면 끌 때까지 모드면 화면 꺼짐 시 해제 상태가 초기화된다.

## 설치

1. [Releases](https://github.com/konor123/sober-lock/releases) 페이지에서 최신 APK(`sober-lock-vX.Y.Z.apk`) 다운로드 (릴리스가 없을 경우 Actions 탭의 `sober-lock-release` 아티팩트 사용)
2. 다운로드한 파일 탭 → "알 수 없는 앱 설치" 허용 → 설치
3. 앱 실행 → **마이크 권한 허용** (랩 테스트에 필요)
4. **접근성 설정 열기** → 설치된 앱에서 "맑은잠금" 활성화
   - Android 13+: 사이드로드한 앱은 설정 > 앱 > 맑은잠금 > 오른쪽 위 ⋮ > "제한된 설정 허용"을 먼저 켜야 접근성 활성화가 가능하다
5. **배터리 최적화 제외 요청** (백그라운드에서 서비스가 죽지 않도록)
6. 잠글 앱을 선택하고 해제 유지 시간을 정한다

## 빌드

- 로컬 Gradle 빌드는 불가하므로 GitHub Actions가 정식 빌드 경로다. `main`에 푸시하면 release APK가 빌드되어 Artifacts에 업로드된다.
- 릴리스: `app/build.gradle.kts`의 versionCode/versionName을 올리고 CHANGELOG.md를 작성한 뒤 `git tag vX.Y.Z && git push origin main vX.Y.Z` (태그는 사용자가 지시할 때만 만든다)

## 한계

- 음성인식(SpeechRecognizer)은 기기·네트워크에 의존한다. 오프라인 인식이 안 되는 기기에서는 네트워크가 필요할 수 있다.
- 안드로이드 특성상 100% 우회 방지는 불가능하다. 안전모드, ADB, 앱 삭제 등으로 우회할 수 있으나, 취한 상태에서는 그럴 여유를 주지 않는 수준의 마찰을 만드는 것이 목적이다.
- 옆 사람이 대신 랩을 읽거나 점을 터치해 주는 것은 막을 수 없다.
